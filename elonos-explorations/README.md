# Kunlun Portfolio — Creative Exploration (v0.1)

Four distinct portfolio **archetypes** for Kunlun to review and choose from.
Per Max's brief: this is the **divergence phase** — not polish. The goal is four genuinely different concepts, not variations on one layout.

**Design Lead:** Max (Hermes) · **Execution:** Duke · **Reviewer:** Kunlun

Positioning being expressed: *Senior IC designer → product-level capability owner → AI-native product/design leader → possible founder.* Systems thinking, not just UI craft. ~65% Apple restraint + 35% Google clarity. Human warmth, no gimmicks.

Each is a **single-file, zero-build, fully static** HTML page. Real copy for all four case studies (MSN Play, Personal Finance Agent, AI-native workflow, Taste-loop experiments). View at desktop 1440px.

## The four directions

### A — System Shell · `direction-a-system-shell.html`
**Thesis:** "I run my design practice like an operating system."
A calm, **purpose-built OS dashboard** (not a macOS clone, not floating-window toy). Projects = Applications, case studies = running Workflows, the agent crew = system Processes (Activity Monitor · Design Ops), design principles = System Preferences, evidence = Diagnostics. Content is up front and readable; case studies expand in place.
- **Strength:** Proven lineage (ElonOS family), most "product systems operator" signal.
- **Risk:** Closest to SaberOS — must stay original, not a desktop clone.
- **Holds:** All 4 cases as apps/workflows + processes + preferences + diagnostics.

### B — Studio Memory Wall · `direction-b-memory-wall.html`
**Thesis:** "Step into the thinking room — where the judgment gets made."
A warm **paper/linen studio wall**: case studies as pinned pure-CSS artifacts (polaroids with faux screenshots, taped index-cards), writing as **marginalia**, process as a taped filmstrip. Senior tone kept via trajectory chips + systems copy.
- **Strength:** Human warmth + taste/process as first-class content. Most personal.
- **Risk:** Can drift cute/casual; must hold the strategic/leadership signal.
- **Holds:** Cases as artifacts, process story, "who's in the room" (Kunlun/Max/Duke).

### C — Strategy Atlas · `direction-c-strategy-atlas.html`
**Thesis:** "A working atlas of the systems I design."
A calm **command-center / constellation**: a central identity hub with four connected **system domains** (Engagement, Finance & Trust, AI Workflow, Research). Click a node → a drawer reveals layers (user behavior → mechanics → AI capability → business outcome) + metrics. A live **Design Ops processes** panel shows the agent crew. Legend focuses a domain and lights its links.
- **Strength:** Most differentiated; reads as AI-native product *strategist*, not a dashboard.
- **Risk:** Can feel abstract/consultant-y if copy isn't concrete (mitigated with real metrics).
- **Holds:** Each case as a domain with a 4-layer system breakdown + proof metrics.

### D — Radical Minimal · `direction-d-radical-minimal.html`
**Thesis:** "Few words. Few objects. Only the essential proof."
The **Jobs / Ive "less is more"** direction. Near-empty first screen with one strong sentence (large Newsreader serif), then a slow scroll-reveal of **3 core works**, each as one line + one result. Four short principles. No gimmick interactions — only subtle reveal, a progress hairline, and corner marks.
- **Strength:** Highest-taste, most senior if it holds substance. Memorable without metaphors.
- **Risk:** Can read empty/content-poor if the framing isn't strong enough.
- **Holds:** Fewer projects, stronger framing — quality over quantity, by design.

## How to compare (Max's review criteria)
1. **Distinctiveness** — ownable by Kunlun, or a Jesse/Saber clone?
2. **Strategic fit** — AI-native product/design *leadership*, not just craft?
3. **Content capacity** — can it hold MSN Play, Finance Agent, AI workflow, experiments?
4. **Interaction meaning** — is the metaphor meaningful or decorative?
5. **Taste potential** — can it become refined, calm, premium?
6. **Execution feasibility** — can Duke build a strong v0.2 fast?
7. **Reviewer clarity** — does Kunlun get it in 10 seconds?

**Max's initial hypothesis:** C may be most original + career-aligned; D may be highest-taste/most senior if executed with substance; B adds warmth; A is proven but risks SaberOS-proximity. A plausible final route is **C-level strategic structure with D-level restraint**.
