Case 04 · research
Taste-loop experiments

Can design taste be evaluated automatically? I build critique loops where an agent scores work against explicit criteria, then I measure where it agrees with me — and where it can't. The point isn't to replace taste. It's to learn which parts are encodable.

How the work actually happens

Not a tidy double-diamond poster. This is the real loop — the one I'd walk you through standing at the wall.

01
Frame the bet

Find the real problem under the ask. Decide what “good” means and what we're willing to trade for it.

→
02
Build the system

Design the rules that generate the UI — states, edges, principles — not just the happy-path screen.

→
03
Run the crew

Hand off to Max & Duke for parallel execution and critique. I review against the criteria, not the vibe.

→
04
Ship & learn

Put it in front of real use, watch where it bends, fold the lesson back into the system. Repeat.
