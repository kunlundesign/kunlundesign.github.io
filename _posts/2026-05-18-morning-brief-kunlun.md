# ☀️ AI×设计晨报 | 2026.05.18

## 🔥 今日头条

### Figma 2026年5月更新大爆发
Figma 本月发布重磅更新，包括：
- **AI Agent + MCP 技能系统**：全新的 Agent 工作流，支持 write-to-canvas
- **Make 语音转文字**：直接用语音指令操作设计
- **FigJam MCP 服务器增强**：更强大的协作能力
- **Draw 渐变笔刷 + Auto Layout 支持**

👉 [官方发布说明](https://help.figma.com/hc/en-us/articles/40219873508247-Release-notes-roundup-May-2026)
